# Loess N2O Meta Thesis

毕业论文项目文件，包含正文文档、分析脚本、地理数据、表格和整理后的图表输出。

## Project Structure

- `黄土高原N2O排放的Meta分析-待定稿V2 .docx`: 当前毕业论文正文。
- `ZhouMS-loess20251120.docx`: 英文稿件/论文相关文档。
- `Table1.docx`, `TableS1.xlsx`: 主表、补充数据和作图输入。
- `make_*.R`, `figure_reproduction.R`: 图表和 meta 分析复现脚本，默认从项目根目录运行。
- `make_fig2_1_site_distribution_refined.py`, `make_fig3_5_n_reduction_meta_forest_manuscript.py`: Python 辅助绘图脚本。
- `data/`: 输入数据与地理边界文件。
- `output/doc/`: 修订后的文档输出。
- `output/figures/`: 论文图件、统计汇总和导出数据。
- `output/manuscript_vector_figures/`: 投稿或排版用矢量图。
- `Archive/`: 本地备份归档目录，已加入 `.gitignore`，不再推送到 GitHub。
