# Loess N2O Meta Thesis

毕业论文项目文件，包含正文文档、分析脚本、地理数据、表格和整理后的图表输出。

## Contents

- `正文.docx`: 毕业论文正文。
- `ZhouMS-loess20251120.docx`: 英文稿件/论文相关文档。
- `Table1.docx`, `TableS1.xlsx`: 表格与补充表。
- `make_*.R`, `figure_reproduction.R`: 图表和 meta 分析复现脚本。
- `make_fig2_1_site_distribution_refined.py`: 站点分布图辅助脚本。
- `data/`: 输入数据与地理边界文件。
- `output/doc/`: 修订后的文档输出。
- `output/figures/`: 论文图件、统计汇总和导出数据。
